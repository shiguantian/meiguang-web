# BuildPilot AI 建站平台

这是一个面向商业化 SaaS 的 AI 建站平台 MVP。目标不是单次生成静态页面，而是让用户持续通过聊天修改站点，并自动发布到自己的云服务。

## 当前版本

- AI 建站工作台界面
- 聊天式修改站点
- 实时桌面/手机预览
- 页面结构管理
- 版本记录与回滚入口
- nginx 云服务器发布中心
- 套餐与计费入口
- 云服务配置入口

## 推荐产品架构

- 前端：React / Next.js 工作台
- 后端：Node.js API 服务
- 数据库：PostgreSQL 存用户、站点、页面、版本、发布记录
- 队列：Redis + Worker 处理生成、构建、发布任务
- 存储：对象存储保存图片、Logo、构建产物
- AI：生成页面结构、文案、图片提示词、主题参数和修改补丁
- 发布：静态构建产物上传到用户云服务器 nginx，使用 releases + current 软链接实现回滚
